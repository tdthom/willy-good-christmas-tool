    Roof Measure (Top View)

    Use a satellite or drone screenshot to measure ridge, hips, eaves, and gable returns from above. Gable returns are tracked separately so you can allow for extra wire and tie-in waste.

    1. Upload a top-down screenshot of the roof.
    2. Click Set scale and draw a line of known length (for example, a 40 ft front wall).
    3. Select run type and click Measure runs, then click along the roof lines.

    Photo / Front View Mockup

    Upload a front photo or Google Street View screenshot, then draw where the lights will go. This screen is visual only – it does not affect your estimate numbers, except for decoration counts.

    1. Upload a photo of the front of the house.
    2. Choose the run type (roof, ground, trees, other).
    3. For straight lines, click start and end. For curves, use Curve run (click & drag).
